# SFpark external validation requirements

Obtain a bounded sample of the official 2011–2013 hourly parking sensor archive before bulk transfer. Required fields are stable block identifier, hour timestamp and timezone/interval semantics, TOTAL_TIME, TOTAL_OCCUPIED_TIME, TOTAL_VACANT_TIME and TOTAL_UNKNOWN_TIME. Obtain monitored-space counts or inventory histories, operating/tow-away rules, coverage dates and outage exclusions. Verify the archive-specific reuse terms and retain source URL, retrieval date and hashes. [Official archive](https://www.sfmta.com/getting-around/drive-park/demand-responsive-pricing/sfpark-evaluation)

Define observed occupancy using occupied divided by occupied plus vacant time, and quality using unknown divided by total time. Zero denominators need explicit exclusions. Hourly quality totals become available only after the hour closes. All input aggregates must end by the forecast origin. Hourly time-weighted block occupancy differs from Birmingham instantaneous counts. Fit and assess the methods within SFpark on a prespecified compatible target before considering cross-dataset model transfer. [Sensor data guide](https://www.sfmta.com/sites/default/files/reports-and-documents/2018/08/sfpark_dataguide_parkingsensordata.pdf)

For 60/120-minute prediction, define the future hourly interval and its timestamp explicitly. A 30-minute task requires finer-resolution timestamped sensor events with stable space IDs, valid/unknown state histories, receipt times where available, sensor coverage and monitored capacity. Hourly aggregates cannot supply that target without unverifiable interpolation.

Use chronological training, validation, calibration and reserved test periods, plus held-out blocks. Apply the guide's exclusions, including its documented December 2012 outage and West Portal guidance. Quality fields quantify observation coverage; independent accuracy evaluation requires manual observations or a verified audit sample joined by location and time. Unknown time alone cannot establish ground-truth occupancy during missing intervals. Freeze the Birmingham hypothesis and decision criteria before inspecting external test outcomes.
