# Reliability and the forecasting decision

For observation t define validity v as an in-range finite reading, age a as minutes since the usable source timestamp and d as absolute change in the carried occupancy fraction. Observation evidence is o = v exp(−a/60)(1−d). Window evidence c is the fraction of the last three observed inputs that satisfy physical bounds. The gate q = oc is in [0,1]. The twelve-reading trailing valid fraction gives a separate historical site indicator. Completeness is conditional on observed opportunities. Neither c nor past validity estimates hardware uptime.

The gate has no learned quality supervision. Its assumptions are that old or invalid inputs provide less useful information and that abrupt changes deserve less weight. Rapid genuine demand changes can violate the latter assumption. q is a heuristic weight. Injected failure assignments supervise only its diagnostic evaluation. Forecast fitting uses the same measured future occupancy for all scenarios.

M0 uses persistence and daily/weekly matches on the observed input stream. Seasonal missing history falls back to persistence, then training median when no observation exists. M1 fits histogram gradient boosting to observed occupancy history, nominal target calendar, capacity and site. M2 uses the same learner plus age, validity flags, change, completeness, historical quality and q. M3 combines that exact fitted M2 prediction with a calendar/capacity/site model as q·M2 + (1−q)·calendar. The explicit mechanism changes the prediction at inference. M2 can learn a different response to identical quality information. A naive M3 versus M1 comparison confounds that mechanism with feature access.

Point forecasts and intervals are bounded by physical capacity. Each model/horizon uses its own clean calibration absolute-error order statistic at rank ceil(0.9(n+1)). Intersect the symmetric prediction interval with [0,1]. Interval score at alpha=0.1 adds interval width and twenty times the distance outside the interval. Serial dependence, simulated shifts and finite coverage windows limit interpreting nominal coverage as a guarantee.
