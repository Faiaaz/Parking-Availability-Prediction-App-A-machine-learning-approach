# Data provenance v2

Actual downloads, URLs, byte ranges, sizes and SHA-256 checksums appear in results/v2/download_manifest.json. Raw external files live in ignored data/external/v2. Recreate bounded downloads with python -m research.multidata.acquire. It accepts existing cached files and records their current checksums; compare those with the recorded manifest to detect upstream changes.

Prior reliability evaluations load only Birmingham. The v2 reproduction also loads only Birmingham. The v2 pilot reads Birmingham and the Harvard measured-column prefix for forecasting. It reads the Melbourne bounded sample for interval-schema counts only. Harvard simulated taxi columns are inspected in the schema and excluded from predictors and targets. SFMTA hourly data and Melbourne 2018 contribute no records.

Adapters distinguish measured sensor references and reconstructed event intervals. Independently verified occupancy truth and verified hardware faults are unavailable. Simulated input corruption labels are generated by code. Harvard source timestamps are assumed immediately available for the measured-column experiment. Melbourne interval records are conservatively assigned availability at the recorded interval end, since their historical release latency is unknown. Retrospective event labels must not be used to reveal an interval's eventual departure at its arrival.
